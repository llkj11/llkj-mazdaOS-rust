Both files were verified against their GitHub blob identities. Font data is bundled
in the executable. No system font discovery, font downloads, or network access is
required at runtime. Swash shapes and rasterizes outlines with pixel coverage
antialiasing; text uses actual advance widths and bounded caches. Font size is
8–96 pixels; metadata is limited to 256 Unicode scalars. Unsupported characters
use a visible `?`. This increment does not provide complete international text
layout, bidirectional text, CJK fallback, or native accessibility semantics.
